# Microsoft Azure: Administrative Roles & Access Management

## Project Overview
Explored Microsoft Entra ID administrative roles within the Microsoft Azure environment to understand role assignments, access permissions, and security responsibilities. Reviewed how administrative privileges are distributed based on job functions and the principle of least privilege.

## Roles & Responsibilities

- **Global Administrator:** Provides the highest level of administrative access, including the ability to manage users, settings, and administrative roles.
- **Reader Roles:** Provide view-only access to resources and information without the ability to make changes. Examples include Security Reader, Global Reader, and Reports Reader.
- **Privileged Role Administrator:** Manages privileged role assignments and administrative access.
- **Security Administrator:** Manages security-related settings, policies, and configurations. This role may support security operations teams and cloud security functions.
- **Conditional Access Administrator:** Manages Conditional Access policies that help enforce Zero Trust principles by evaluating access based on defined conditions.

## Key Takeaways
- Understanding the differences between administrative and read-only permissions.
- Recognizing the importance of limiting privileged access.
- Connecting administrative roles to organizational job responsibilities.
- Understanding how role-based access control supports security and least privilege.
- Exploring how Conditional Access contributes to Zero Trust security.
